# Highlights support six colors

| Color  | Markdown Syntax       | Preview             |
| ------ | :-------------------- | :------------------ |
| Red    | `==🔴Important==`     | ==🔴Important==     |
| Orange | `==🟠Follow up==`     | ==🟠Follow up==     |
| Yellow | `==🟡Remember this==` | ==🟡Remember this== |
| Green  | `==🟢Done==`          | ==🟢Done==          |
| Blue   | `==🔵Reference==`     | ==🔵Reference==     |
| Purple | `==🟣Idea==`          | ==🟣Idea==          |

> Without a color emoji, the highlight uses your theme's default highlight color.
